Loredrop pour calculatrices NumWorks (N0110, N0115, N0120) — 3D à la première personne.

**Installer :** sur ordinateur, dans Chrome ou Edge, ouvrir https://my.numworks.com/apps, brancher la calculatrice et envoyer `loredrop.nwa`. Le jeu apparaît à la fin du menu d'accueil.

⚠️ L'installateur NumWorks remplace les applications déjà installées de cette façon. Le mode examen les cache ou les efface. Le monde n'est pas sauvegardé en quittant.

**Contenu (NW1 à NW5) :** monde infini en 3D (biomes, grottes, minerais, arbres, plantes), survie (vie, faim, outils, fabrication, four), créatures (animaux, zombies, squelettes, araignées, le Hollow), combat, armures, ruines avec tablettes de lore, torches, mode créatif, qualité automatique.

**Pas encore testé sur une vraie calculatrice.** Pour signaler la vitesse : réglages → *Show timings*.

Commandes : flèches = regarder, 8/5/4/6 = marcher, 0 = sauter, OK = miner/frapper, EXE = poser/utiliser/manger, Var = inventaire, Retour = pause, Maison = quitter.
